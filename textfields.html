3. Error

This section covers the key information about error states.

  • Stays on the field. The field stays editable.
  • Indicator, label, trailing icon, supporting text, and caret switch to Red 1.

Empty input

  • Shows on submit if a required value is missing.
  • Supporting text e.g. “URL je povinná”.
  • Try: Upravit · clear URL · tap check.

Invalid format

  • Shows on submit if the value is not a valid e-mail or URL (including javascript:).
  • Supporting text: “Zadejte platný e-mail” / “Zadejte platnou URL”.
  • Try: Upravit URL javascript:alert(1) or Playground e-mail jan@, then leave / save.

Long text

  • Shows while editing, as soon as the value exceeds the limit.
  • “Text je příliš dlouhý (n/2048)”. Bookmark URL limit is 2048 characters. Not truncated.
  • Try: Upravit · URL · paste a string longer than 2048.
  • After an empty or format error is shown, the field keeps validating as the user types so the error clears when the value is fixed. Save is the check in the app bar. Playground has no check — leaving the field is the commit.

4. Working with text

This section covers the key information about working with text.

Entering text

  • While typing, the caret moves right.
  • Single-line fields use an ellipsis when unfocused. While focused, if the value is longer than the field, the text scrolls so the caret stays visible.
  • Feedback body / Password manager. When the caret reaches the end of a line, it wraps to the next line. No ellipsis.

Deleting text

  • While deleting, the caret moves left.
  • On a single-line field, when the caret is at the end, deleting scrolls the text right.

Pasting text

  • After paste, the caret sits at the end of the inserted string.
  • The caret is not jumped to the end of the whole field if the user pasted in the middle. Overflowing single-line fields scroll so that end of the paste stays visible.

Selecting text

  • Clicking into a value and selecting a portion of it sit on focused populated fields.
  • A click or tap places the caret at that index, not only at the end.
  • Double-click selects the word (token). Triple-click selects the entire value.
  • Highlight and handles use Android’s default selection (Holo blue #33B5E5, highlight at 40%). Text stays on-surface — not inverted. Do not restyle with Primary 1 or Red 1. The caret is hidden while a range is selected.
  • Read-only pickers have no text selection.
